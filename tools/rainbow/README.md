## `shots.cjs`

The rainbow wave in the built game: from by home on an island, a wave set off as an early clear would send it from its stone, shot a few times as its two runs go out along the ley line, on to the route's end and back to the spark.

```
npm run build && node tools/rainbow/shots.cjs [out dir]   (ISLAND=fox, SEED=123, SIZE=1280x720, AT="x,z" where she stands, TIMES="1,2.5,4", AHEAD=40)
```
