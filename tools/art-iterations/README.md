## `evolutions.js`

Evolved designs: species drawn with an evolution per level, as genome records the ladder can show beside today's.

## `ladder.mjs`

The stylisation ladder: the same small set drawn at the current look and at steps of increasing pixel-art stylisation, side by side, each at the game's own screen scale.

```
node tools/art-iterations/ladder.mjs <area> <out dir> [artSet]
```
