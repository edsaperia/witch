## `survey.cjs`

The lighting survey: the same seeds and views every time, as screenshots OUT/<seed>-<scene>.png, so a lighting change can be judged before and after.

```
node tools/lighting/survey.cjs [out dir] [extra URL params, e.g. "&light=plain"]
```
