## `dive.cjs`

The loading mist through the dive: the built game loaded at home, then sailed in place to another island, the page's own loop running, a picture every EVERY seconds of the wall's clock from the sail on, each logged with the flight's state and each area…

```
npm run build && node tools/mist/dive.cjs [out] [dist]
```

## `frames.cjs`

The loading mist in the built game, and the order the island's area types load in.

```
npm run build && node tools/mist/frames.cjs [out] [dist]
```
