# Seed-san (the VRM test page's sample model)

`Seed-san.vrm` is the VRM Consortium's sample model, from https://github.com/vrm-c/vrm-specification/tree/master/samples/Seed-san
(`samples/Seed-san/vrm/Seed-san.vrm`), vendored unchanged for `vrm-test.html` only (not in the game).

- Model: Seed-san, by VirtualCast, Inc. (credit required)
- Licence: VRM Public License 1.0, https://vrm.dev/licenses/1.0/
- Its VRM metadata: avatarPermission everyone, commercialUsage corporation, allowRedistribution true,
  modification allowModificationRedistribution, creditNotation required.

# The other models in the picker (fetched by the page, not copied into this repository)

`vrm-test.html` fetches these from their own GitHub repositories, pinned to a commit (raw.githubusercontent.com). Each one's credit
and licence also show on the page when it's picked.

- **VRoid sample (VRM1_Constraint_Twist_Sample)**, by pixiv Inc., from `pixiv/three-vrm` (`packages/three-vrm/examples/models/`).
  Licence: VRM Public License 1.0. Its metadata: allowRedistribution true, modification allowModificationRedistribution,
  creditNotation unnecessary.
- **AvatarSample_A**, by VRoid (pixiv Inc.): VRoid Studio's official sample, from `madjin/vrm-samples` (`vroid/stable/`).
  Licence: VRoid Studio's sample model conditions, https://vroid.pixiv.help/hc/en-us/articles/4402394424089. Those conditions
  allow use, alteration and distribution, per the repository's README; that page couldn't be opened from the build machine.
- **Sendagaya Shino**, by VRoid (pixiv Inc.): a VRoid Studio beta sample, from `madjin/vrm-samples` (`vroid/beta/`). Licence: CC0
  (its metadata and the README).
- **100Avatars #039 Witch**, by Polygonal Mind, from `polygonalmind/100Avatars`. Its metadata says CC0, but the repository's
  licence file is CC BY 4.0, so it's credited.
