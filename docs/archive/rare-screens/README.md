# Stopped rare-screen experiment

Historical evidence, not an active implementation plan. PR #1507 redirected this work to house geometry precomputation (COORDINATOR 6534772261/6534776616, 2026-10-30); #1520 removed the unused loading seam and builder pollers. Product code never imported that seam.

The decision used the compression model in [value-estimate.json](value-estimate.json), based on [startup-before.json](startup-before.json), source `347988785d2413ed5a6ca4e474230aae1ec55907` (runtime identical to `0389ac1e`). Combined movement modeled **73,697 generated bytes / 25,350 gzip9 bytes**, about **1.83%** of initial gzip, before new chunk/bridge costs. Creator: 44,143 / 16,461; Studio: 17,467 / 5,609; DJ: 6,318 / 1,437; Telescope: 4,292 / 1,629; Zoo: 1,477 / 418. Group gzip deltas are not additive. These are source-attributed compression estimates, never measured network or boot savings.

[The stopped plan](plan.md) preserves its original reasoning. [value-estimate.cjs](value-estimate.cjs) is retained for historical reproducibility: run from the repository root only against the original baseline sources, matching source-map build and dependency version. It reads the archived baseline and writes the archived estimate; it is not a current performance check. Git history retains the removed unused seam and its contract tests.
