# Ley line routes: varied, not all spirals (Ed, 2026-10-06)

"Have the builder do a variety pass that mixes in back-and-forth sweeps and lobes so maps aren't all spirals. A map can have at most four crossings, and the crossing lines must be from waves at least 12 apart, and not in the first 12 waves."
